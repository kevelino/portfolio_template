# Portfolio Template

A customizable, open-source developer portfolio built with **Next.js**, [shadcn/ui](https://ui.shadcn.com/), and [Magic UI](https://magicui.design/).

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fkevelino%2Fportfolio_template)

</div>

## Features

- Setup only takes a few minutes by editing the [single config file](./src/data/resume.tsx)
- Built using Next.js, React, Typescript, Shadcn/UI, TailwindCSS, Framer Motion, Magic UI
- Includes a blog with MDX support
- Terminal-style hero with interactive commands (`about`, `skills`, `projects`, `blog`, `contact`, …)
- Responsive for different devices
- Optimized for Next.js and Vercel

## Getting Started Locally

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/kevelino/portfolio_template.git
   ```

2. Move to the cloned directory

   ```bash
   cd portfolio_template
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Start the local server:

   ```bash
   pnpm dev
   ```

5. Open the [Config file](./src/data/resume.tsx) and make changes

## Customization

All personal content lives in the [single config file](./src/data/resume.tsx) — update the name, avatar, skills, socials, and projects to fit your own portfolio.
